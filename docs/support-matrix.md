# Microsoft Fabric support matrix

Verified against official Microsoft documentation on **2026-09-15**. Preview capabilities require explicit tenant acceptance and can change; the deployment scripts do not represent UI-only controls as automated.

| Capability | Status used by this POC | Implementation and boundary |
|---|---|---|
| Direct Lake | GA | Gold Delta tables back the TMDL model. [Direct Lake development](https://learn.microsoft.com/en-us/fabric/fundamentals/direct-lake-develop) |
| PBIP/TMDL semantic model | Preview for project/source deployment | TMDL is committed; enable PBIP and TMDL project preview features before Desktop editing. [PBIP overview](https://learn.microsoft.com/en-us/power-bi/developer/projects/projects-overview), [semantic model project format](https://learn.microsoft.com/en-us/power-bi/developer/projects/projects-dataset) |
| Enhanced PBIR report | Preview | Enhanced report definition is committed; enable PBIR preview. Do not hand-edit legacy `mobileState.json`. [PBIR format](https://learn.microsoft.com/en-us/power-bi/developer/projects/projects-report) |
| Semantic model/report item APIs | Fabric v1 available; source formats preview | Deployed with `fabric-cicd`; destination source binding is parameterized. [semantic model API](https://learn.microsoft.com/en-us/rest/api/fabric/semanticmodel/items), [report API](https://learn.microsoft.com/en-us/rest/api/fabric/report/items) |
| Lakehouse metadata | GA REST/ALM | Metadata deploys, but tables and Files do not; the notebook and Azure Storage SDK populate the target. [Lakehouse ALM](https://learn.microsoft.com/en-us/fabric/data-engineering/lakehouse-git-deployment-pipelines), [lakehouse API](https://learn.microsoft.com/en-us/rest/api/fabric/lakehouse/items) |
| Notebook source/deployment | GA | Source-controlled notebook is deployed and run through the jobs API. [Notebook source control](https://learn.microsoft.com/en-us/fabric/data-engineering/notebook-source-control-deployment), [notebook API](https://learn.microsoft.com/en-us/rest/api/fabric/notebook/items) |
| `fabric-cicd` | Microsoft-supported tool | Deploys the supported item scopes in dependency order. [Official documentation](https://microsoft.github.io/fabric-cicd/latest/) |
| ADLS Gen2/Amazon S3 shortcut | GA; REST v1 | Connection must already exist; deployment creates or replaces only the POC shortcut. S3 is read-only. [OneLake shortcuts](https://learn.microsoft.com/en-us/fabric/onelake/onelake-shortcuts), [shortcut API](https://learn.microsoft.com/en-us/rest/api/fabric/core/onelake-shortcuts/create-shortcut) |
| RLS definitions | GA; role members not source-deployable | TMDL contains filters. Membership and Test as role are manual; workspace Admin/Member/Contributor bypass model RLS. [RLS](https://learn.microsoft.com/en-us/fabric/security/service-admin-row-level-security) |
| Fabric data agent | Product GA; configuration management/publish API preview | The official `Files/Config` draft definition deploys through `fabric-cicd`; operators validate and publish in UI. [Definition format](https://learn.microsoft.com/en-us/rest/api/fabric/articles/item-management/definitions/data-agent-definition), [concepts](https://learn.microsoft.com/en-us/fabric/data-science/concept-data-agent), [REST APIs](https://learn.microsoft.com/en-us/rest/api/fabric/dataagent/items) |
| Standalone Power BI Copilot | Preview, tenant/capacity/region dependent | Tenant admin enables and scopes it; model is separately marked Approved for Copilot. [Admin settings](https://learn.microsoft.com/en-us/fabric/admin/service-admin-portal-copilot), [Power BI setup](https://learn.microsoft.com/en-us/power-bi/create-reports/copilot-enable-power-bi) |
| Semantic model AI preparation | Preview | Apply AI schema/instructions/verified answers and refresh in service. [Prep data for AI](https://learn.microsoft.com/en-us/power-bi/create-reports/copilot-prepare-data-ai) |
| Power BI mobile | iOS/Android GA; Windows app retired | Publish the thin report/app, create phone layout in supported authoring UI, optionally manage through Intune. [Mobile apps](https://learn.microsoft.com/en-us/power-bi/explore-reports/mobile/mobile-apps-for-mobile-devices), [Intune](https://learn.microsoft.com/en-us/fabric/enterprise/powerbi/service-admin-mobile-intune) |
| Fabric lineage | GA UI; relation APIs beta | Workspace lineage provides item relationships and one external upstream level, not external object/field lineage. [Fabric lineage](https://learn.microsoft.com/en-us/fabric/governance/lineage) |
| Purview Fabric scanning | GA; shortcut stitching unsupported | Scan Fabric and ADLS separately. Non-Power-BI Fabric lineage is item-level; automatic shortcut-to-external-object/subitem lineage is not supported. [Register and scan Fabric](https://learn.microsoft.com/en-us/purview/register-scan-fabric-tenant), [Purview with Fabric](https://learn.microsoft.com/en-us/fabric/governance/microsoft-purview-fabric) |
| OneLake Catalog endorsement | GA/tenant-dependent; no documented source API | Apply Promoted/Certified/Master data in item settings. [Endorsement](https://learn.microsoft.com/en-us/fabric/governance/endorsement-overview), [apply endorsement](https://learn.microsoft.com/en-us/fabric/fundamentals/endorsement-promote-certify) |
| Capacity Metrics app | GA | Use its supported reports for 14-day CU-second attribution. Its supplied model is not a supported custom telemetry API. [Install](https://learn.microsoft.com/en-us/fabric/enterprise/metrics-app-install), [overview](https://learn.microsoft.com/en-us/fabric/enterprise/metrics-app), [Compute page](https://learn.microsoft.com/en-us/fabric/enterprise/metrics-app-compute-page) |
